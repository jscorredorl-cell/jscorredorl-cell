## 🚀 superagentycs

[**superagentycs.com**](https://superagentycs.com) es mi proyecto principal: una plataforma de **agentes de IA para tu negocio**. Conectamos el agente a las herramientas que tu equipo ya usa (ventas, soporte, facturación, canales de contacto), definimos juntos límites, tono y reglas de escalado, y lo lanzamos con supervisión y métricas.

**Qué hacen los agentes**

| Área | Qué resuelven |
|---|---|
| 🎧 Atención al cliente | Consultan pedidos, gestionan devoluciones y cambios, y escalan a una persona con todo el contexto. |
| 💼 Ventas | Califican leads, responden dudas de producto y agendan reuniones con el comercial correcto. |
| 📊 Análisis de datos | Responden preguntas de negocio en lenguaje natural con tus datos y preparan reportes. |

**Cómo trabaja**

1. **Conectamos tus sistemas**: sin migrar nada.
2. **Entrenamos al agente** con tu equipo y lo probamos con casos reales.
3. **Lanzamos y medimos**: un panel muestra resoluciones, ahorro y casos escalados.

**Seguridad primero:** tus datos no se usan para entrenar modelos, cada agente opera con permisos mínimos, todo queda registrado y una persona siempre puede intervenir.

**Stack:** Python · FastAPI · LangChain / LangGraph · Gemini y Claude · BigQuery · PostgreSQL · React 19 + Vite + TypeScript · Docker · Cloud Build · API Gateway · Google Cloud.

La web incluye un **playground** para probar tres agentes en vivo: profesor de matemáticas, analítica sobre BigQuery y atención al cliente de una tienda demo.

## 🧩 Agentes open source

Tres agentes de ejemplo, completos y documentados, para aprender y reutilizar:

### [Customer Service](https://github.com/jscorredorl-cell/Customer-Service)
Agente que consulta, cancela y devuelve órdenes. Verifica el estado real de la orden, decide entre cancelar o devolver, **pide confirmación** y registra la solicitud.
`Google ADK` · `Gemini` · `BigQuery` · `Vertex AI Agent Engine`

### [Data Analyst](https://github.com/jscorredorl-cell/data-analyst)
Hazle preguntas a tus datos en lenguaje natural. Explora tus archivos, escribe el SQL, lo ejecuta y, si falla, lo corrige solo. Cada número sale de una consulta real.
`LangGraph` · `DuckDB` · `Gemini` · `Vertex AI`

### [RAG Agent](https://github.com/jscorredorl-cell/rag-agent)
Hazle preguntas a tus documentos. Busca en tus PDFs y responde con la fuente exacta (capítulo y página); si la respuesta no está, te lo dice.
`LangGraph` · `PostgreSQL + pgvector` · `Gemini` · `Vertex AI`
